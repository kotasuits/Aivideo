⚡ How this works
Your API key is saved only in your browser — never sent anywhere except Google's servers.
Video generation is a long-running operation. It takes 2–5 minutes — the page polls automatically every 10 seconds.
Veo 3.0 requires a paid AI Studio / Gemini API account (billing enabled). Veo 2.0 is available on the free tier with limits.
If you get a CORS error, use the Python backend version below — browsers cannot call the Gemini Files API directly for large uploads.
Image is converted to base64 and sent as inline data — works for images under ~5 MB.
🎯
Great Prompts
Mention camera motion (pan left, slow zoom), lighting (golden hour, neon), and subject action (waves crashing, petals falling).
🖼️
Best Images
Clear, high-res scenes work best. Landscapes, portraits, cityscapes, and nature shots animate beautifully.
❌
CORS Error?
Run the Python script (see README) which acts as a local proxy. Browsers block direct calls to some Google endpoints.
🔑
Free Tier Limits
Veo 2.0 has limited free quota. For unlimited use, enable billing in Google Cloud Console and use a paid key.
